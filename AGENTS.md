# Anweisungen für KI-Agenten

Alle Anweisungen für dieses Repository stehen in **[.github/copilot-instructions.md](.github/copilot-instructions.md)**.
Lies diese Datei zuerst vollständig und befolge sie; danach `docs/stand.md`.

Die drei wichtigsten Regeln, falls nur diese Datei geladen ist:
1. Keine Inhalte interner Helsana-Studien in Chat, Dateien oder Commits – nur IDs (LAV-NN) und Prüfkennzahlen.
2. Das Repository ist öffentlich: nur Skills, Werkzeuge, Doku und die öffentlichen Teststudien LAV-T01–T03.
3. Dateien mit Kontrollwörtern nie in einen Copilot-Studio-Agenten hochladen lassen.

Antworten auf Deutsch (Schweiz: kein «ß», 1’204). Tests und Build: `python tools/build.py`.
